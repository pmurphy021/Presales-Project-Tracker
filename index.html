Supabase Credentials & Sync Setup

Instructions: Enter your Supabase Project URL and Public Anon Key.

Make sure you have created the projects table in your Supabase SQL editor using this schema: 
create table public.projects (
  id text primary key,
  pillar text,
  title text,
  description text,
  lead text,
  next_step text,
  progress integer,
  priority text,
  status text,
  start_date text,
  due_date text,
  blockers text,
  effort text,
  subtasks jsonb,
  updated_at timestamp default now()
);
